# 皮肤站(非正版玩家必读)

非正版 Java 玩家通过 **BlessingSkin 皮肤站**(外置登录)进服。DreamPort 与皮肤站已深度打通,**大部分事情系统会自动帮你做完**。

## 账号怎么来的

### 新注册玩家(全自动)

注册 DreamPort 时玩家类型选「**非正版 Java(皮肤站)**」,提交后系统自动为你开通:

- ✅ 皮肤站账号(邮箱与 DreamPort 相同)
- ✅ **密码与 DreamPort 完全相同**
- ✅ **1000 初始积分**(用于上传皮肤等)
- ✅ **同名角色**(就是你的游戏 ID)

注册完成即可直接[配置启动器](#配置启动器),无需再去皮肤站注册。

### 老玩家(互通上线前注册的)

两种方式任选:

1. **控制台一键开通**:控制台「皮肤站角色」卡 → 点「一键开通」→ 输入当前 DreamPort 密码 → 完成(密码与 DreamPort 同步)
2. **去皮肤站点一次登录**:皮肤站登录页点「使用 DreamPort 账号登录」→ 授权 → 自动建号(这种方式的初始密码是随机的,**去 DreamPort 改一次密码**,新密码会自动同步到皮肤站)

## 登录皮肤站(网页)

皮肤站登录页只有一个按钮:**「使用 DreamPort 账号登录」**。

1. 点击 → 跳转到 DreamPort 授权页
2. 点「**允许授权**」
3. 自动跳回皮肤站,登录完成

以后每次都这样登,不用记两套密码。管理员开启纯 SSO 模式后,皮肤站网页只能用这种方式登录。

## 配置启动器

以 HMCL / PCL2 等支持外置登录(authlib-injector)的启动器为例:

1. 打开启动器 → 选择/新建版本 → **版本设置** → 找到「服务器」/「外置登录」选项
2. 填入皮肤站地址(以站点实际地址为准,例如 `http://skin.xmcraft.cn`),启动器会自动识别
3. 登录方式选择「外置登录」,输入:
   - 账号:你的**邮箱**(与 DreamPort 相同)
   - 密码:你的 **DreamPort 密码**
4. 启动游戏 → 正常进入服务器

> 改了 DreamPort 密码?皮肤站密码会**自动同步**,用新密码登录启动器即可。

## 皮肤与角色管理

登录皮肤站用户中心后:

| 功能 | 说明 |
|---|---|
| 上传皮肤 | 用户中心 → 我的皮肤;支持 Slim/Alex 模型;上传消耗少量积分 |
| 上传披风 | 同上,材质类型选 cape |
| 添加角色 | 默认角色已自动创建;再加角色会消耗积分(以站点设置为准) |
| 3D 预览 | 官网控制台「皮肤站角色」卡直接展示你的 3D 头像与皮肤/披风链接 |

积分用途:上传材质、添加角色等;初始 1000 分,部分站点行为可获得积分(签到等以站点开放的功能为准)。

## 改密码 / 改游戏名怎么办

| 操作 | 结果 |
|---|---|
| 在 **DreamPort** 改密码 | ✅ 皮肤站密码自动同步,启动器用新密码 |
| 在 **DreamPort** 改 Minecraft ID | ✅ 皮肤站角色自动改名(新名被占用时会提示) |
| 在 **DreamPort** 改邮箱 | ✅ 皮肤站邮箱先同步,成功后本站才生效 |
| 在皮肤站直接改 | 不建议——以 DreamPort 为准,皮肤站侧改动不会反向同步 |

## 游戏内看不到皮肤?

1. 确认皮肤上传到了皮肤站且已「应用」到你的角色
2. 确认启动器走的是外置登录(皮肤站账号),不是离线模式直接进
3. 重新进服或按 F5 刷新;正版玩家皮肤来自微软账号,与皮肤站无关
