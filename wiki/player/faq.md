# 玩家常见问题

## 进服被踢?对照这张表

| 踢出提示 | 原因 | 解决 |
|---|---|---|
| 你还未注册白名单,请先在官网注册(+网址) | 游戏名没注册 | 去官网注册;**名字必须完全一致** |
| 账号正在等待问卷完成 | 问卷没做 | 官网做问卷 |
| 问卷已通过,等待管理员审核 | 还在人工审核 | 等待,群里催催 |
| 等待邀请人确认 | 邀请码注册流程未走完 | 联系邀请你的人 |
| 已记录信息,请回网页继续 ID 验证 | 审核通过但没验证 | 3 分钟内回官网点「验证 ID」 |
| 你的申请已被拒绝 | 审核被拒 | 控制台提交申诉 |
| 你已被封禁 | 违规被封 | 看封禁原因;临时封禁到期自动解封 |
| 服务器维护中 | 管理员开了维护模式 | 等维护结束(OP 不受影响) |
| 其他/未知 | 状态异常 | 联系管理员查后台 |

> 后端临时宕机时服务器按管理员设置的策略放行或拒绝,一般很快恢复。

## 注册 / 登录

**收不到邮箱验证码?**
检查垃圾箱;确认邮箱域名没被站点白名单拦;仍不行就找管理员(或用邀请码注册)。

**提示"游戏名不合法"?**
游戏名只能用 3-16 位**字母、数字、下划线**,不允许 `-`、中文等字符(与皮肤站规则保持一致)。

**同一邮箱能注册几个号?**
默认 3 个,以站点设置为准。

**忘记密码?**
官网登录页「忘记密码」,走邮箱重置流程。非正版玩家重置后皮肤站密码同步更新。

## QQ 绑定

**`/dp 绑定` 说申请过于频繁?**
验证码限频:每分钟 1 次、每天 5 次。等一会儿再试。

**验证码没私聊发给我?**
机器人私聊失败(可能是隐私设置)。私聊机器人发「dp 绑定」重试;持续失败联系管理员检查配置。

**验证码过期?**
5 分钟有效,重新发一个即可;后端重启也会让旧码失效。

**解绑后群昵称还显示绑定信息?**
机器人不管群昵称,自己改一下就行。

## 皮肤站(非正版)

**控制台显示"尚未开通皮肤站账号"?**
点「一键开通」输入 DreamPort 密码;或去皮肤站点一次「使用 DreamPort 账号登录」。

**启动器登录失败?**
确认:①账号是**邮箱**;②密码是 DreamPort 密码(改过 DreamPort 密码就用新的);③启动器外置登录地址填的是皮肤站地址。

**皮肤游戏里不显示?**
确认皮肤已上传并「应用」到角色;确认走外置登录进服;实在不行重进一次。

**皮肤站角色名能改吗?**
能——在 DreamPort 控制台修改 Minecraft ID,皮肤站角色自动改名(新名被占用会提示)。

**积分不够上传皮肤?**
初始 1000 分;上传消耗很少。可参与站点活动获取,或联系管理员。

## 其他

**网页聊天室发消息没反应?**
可能有频率限制(每分钟 10 条)或触发了敏感词过滤(显示为 `***`)。

**照片墙留言不见了?**
站点开启先审后发时,留言要等管理员审核通过才展示。

**收到封禁邮件但觉得冤?**
临时封禁到期自动解封;永久封禁通过申诉通道提交,管理员会复核。
