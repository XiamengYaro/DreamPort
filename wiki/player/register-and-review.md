# 注册 · 问卷 · 审核

## 注册账号

打开官网 `/register`,按提示填写:

| 字段 | 说明 |
|---|---|
| 玩家类型 | **正版 Java** |
| Minecraft ID | Java 玩家必填。3-16 位**字母数字下划线**(不允许 `-`) |
| 基岩版 ID | 纯基岩版必填,或 Java 玩家勾选「同时注册基岩版」;系统自动加 `.` 前缀 |
| 邮箱 | 需输入邮箱验证码;同一邮箱可注册的账号数有上限(默认 3 个);可能受域名白名单限制 |
| 密码 | 至少 6 位 |

提交成功后自动登录并跳转到验证引导页。

> **管理员可能开放邀请码注册**:拿到邀请码的玩家可免邮箱验证码直接注册,并自带邀请关系(邀请人可见邀请记录)。

## 问卷

登录后从控制台进入问卷:

- 题目由管理员配置,答案提交后系统评分
- 评分方式:站点可开启 **AI 评分**(自动打分+评语),低置信度自动转人工
- 分数达到**及格线**(默认 60 分,管理员可调)即为「问卷通过」,进入人工审核阶段
- 问卷结果可在官网查看(分数与评语摘要)

## 审核状态

控制台与 [/status 页](#)可随时查看进度:

| 状态 | 含义 | 你要做什么 |
|---|---|---|
| `pending` | 已注册,问卷未完成 | 去做问卷 |
| `pending_review` | 问卷通过,等待管理员审核 | 耐心等待,可在 QQ 群催一催 |
| `pending_verify` | 审核通过,等待 ID 验证 | 进服后点验证,见 [ID 验证](verify-identity.md) |
| `approved` | ✅ 全部完成 | 正常游玩 |
| `rejected` | 被拒绝 | 可在控制台提交**申诉** |
| `banned` | 被封禁 | 查看封禁原因;临时封禁到期自动解封 |

管理员审核通过/拒绝/封禁时,你会收到**站内通知**(铃铛)和**邮件**(如站点已配置 SMTP)。

## 申诉

- 问卷被拒或账号被拒绝:控制台出现**申诉入口**,填写申诉理由提交
- 管理员处理后在控制台展示处理结果(附管理员回复)
- 封禁相关:临时封禁到期自动解封;永久封禁走申诉通道

## 邀请码注册(如开放)

- 老玩家在控制台生成邀请码,新玩家凭邀请码注册可**跳过邮箱验证码**
- 每个玩家可生成的邀请码数量与有效期由管理员设置
- 注册后邀请关系入库,管理员可见来源
