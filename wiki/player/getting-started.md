# 玩家快速上手

欢迎来到 **夏日小镇 · 梦港**!这份文档帮你搞清楚:**要进我们的服务器,你需要做哪几步**。

---

## 先看看你是哪种玩家

| 你的情况 | 进服方式 | 你要做的事 |
|---|---|---|
| 💎 **正版 Java 玩家** | 正版账号直接进服 | 注册 → 答问卷 → 过审核 → 验证 ID |
| 📱 **纯基岩版玩家** | 基岩版进服 | 注册(选「纯基岩版」)→ 过审核 → 验证基岩 ID |

> 不管哪种,前两步都一样:**在官网注册账号 + 完成问卷**,审核通过后才能进服。

---

## 第一步:注册账号

打开官网 → 点「注册」:

1. **选择玩家类型**(正版 / 非正版 / 纯基岩版)
2. Java 玩家填写你的 **Minecraft 游戏名**(3-16 位字母数字下划线,之后就是你在服务器里的名字)
3. 填写邮箱并输入验证码,设置密码
4. 提交注册,自动登录进入[控制台](#)


## 第二步:完成问卷

在官网做一份问卷(约 10 题),系统评分(可开启 AI 评分):

- **达到及格线** → 进入管理员人工审核
- **未达及格线** → 会提示未通过,可以[联系管理员申诉](register-and-review.md#申诉)

## 第三步:等待审核

控制台首页能看到实时进度:

```
注册成功 → 问卷完成 → ✅ 问卷通过 → ⏳ 等待管理员审核 → 审核通过
```

审核通过后就可以进服了(非正版玩家先完成[启动器配置](skin-station.md#配置启动器))。

## 第四步:验证 ID

进入服务器后,回到官网控制台点击「验证 ID」(3 分钟内有效):

- **Java 玩家**:用你注册的游戏名进服,点验证
- **基岩玩家**:用基岩 ID 进服(系统自动加前缀),点验证
- **正版玩家**:还可以在控制台绑定 Microsoft 账号

验证成功 = 白名单正式生效,之后每次进服自动放行。

## 顺手可以做的

| 功能 | 在哪 | 说明 |
|---|---|---|
| 💬 QQ 绑定 | 控制台 / 游戏内 | 绑定后可收到通知、参与群服聊天,见 [QQ 与聊天](qq-and-chat.md) |
| 🏠 村民族谱 / 公共机器 | 官网导航 | 展示自己的建筑与红石机器 |
| 🖼 时光照片墙 | 官网首页 | 回顾服务器大事件,可以留言 |
| 🔔 消息通知 | 官网铃铛 | 审核/封禁/公告等重要消息都会通知 |
| 🔑 修改密码/邮箱 | 控制台 | 改密码至少 8 位,改邮箱需邮箱验证码 |
| 🎨 主页装修 | 个人主页 → 自定义主页 | 简介/横幅/背景/社交链接/自定义 CSS,装修模式实时预览,保存后对外生效 |

## 遇到问题?

- 进服被踢?看[玩家常见问题](faq.md)里的**踢出提示对照表**
- 验证码收不到?检查垃圾邮件;测试环境可能是日志模式(问管理员)
- 其他问题:QQ 群内 @管理员,或在群里发 `/dp 状态` 先看看服务器是不是正常的
