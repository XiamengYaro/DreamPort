# ID 验证

## 为什么要验证

审核通过只是「白名单资格」,**ID 验证**是把「网站账号」和「进服的游戏身份」绑定起来:

- 证明这个游戏名真的是你(而不是冒用别人名字)
- 绑定后,服务器内的经济数据、统计、社区展示都会关联到你的账号

## Java 版验证(进服验证)

1. 审核通过后,用你注册时填的 **Minecraft 游戏名**进入服务器
2. 进服后 **3 分钟内**,回到官网控制台点击「**验证 ID**」
3. 系统比对你刚才的进服记录,一致即验证成功 ✅

注意事项:

- 验证窗口 3 分钟,超时重新点一次(系统会重新记录你的进服信息)
- 验证的是**游戏名**,不是网站用户名——但非正版玩家两者本来就是同一个名字
- 换了游戏名?在控制台「Minecraft ID 管理」修改后重新进服验证

## 正版玩家的额外选项:Microsoft 绑定

正版玩家可以在控制台绑定 Microsoft 账号:

- 绑定走微软官方 OAuth 流程,验证等级最高
- 需要管理员已在后台配置 Azure 应用;未配置时会提示"待配置"
- 详见管理员文档,玩家端只需在控制台点「绑定 Microsoft 账号」按提示跳转授权

## 基岩版验证

1. 在控制台「基岩版 ID 管理」填写你的基岩 ID(Xbox/Gamertag,系统自动加 `.` 前缀)
2. 用带前缀的 ID 从基岩端进服
3. 进服后 3 分钟内回官网点「验证基岩版 ID」
4. 成功后基岩白名单生效;可随时「取消验证」解除

## 常见问题

**点验证提示"未找到登录记录"?**
确认真的进服了、游戏名与注册完全一致、并且是在 3 分钟窗口内点的验证。

**验证成功但换号登录被踢?**
换游戏名需要重新修改 ID 并验证,旧 ID 的绑定会被替换。

**被封禁了还能验证吗?**
不能。封禁期间登录校验直接拒绝,解封后恢复,见 [封禁说明](faq.md)。
