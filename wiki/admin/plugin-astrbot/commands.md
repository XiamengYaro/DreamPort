# AstrBot 插件 · 指令与群服桥

## 指令

注册名为 `dp`(前缀 `/dp` 或 `/dreamport` 均可),群聊/私聊均可触发:

| 指令 | 别名 | 功能 |
|---|---|---|
| `/dp 绑定` | `bind` | 申请绑定验证码:后端生成 **6 位一次性验证码(5 分钟)**,群聊时私聊投递;限频 1 次/分钟、5 次/天(触发回复限频提示) |
| `/dp 解绑` | `unbind` | 解除 QQ 绑定(未绑定时提示) |
| `/dp 查询` | `lookup` | 显示本 QQ 绑定的账号与状态 |
| `/dp 状态` | `status` | `服务器在线:{online}/{max} · 群组 {servers} 服 · 版本 {version}` |
| `/dp 玩家` | `players` | 在线玩家列表(前 30 个,标注所在服) |
| `/dp 帮助` | `help` | 指令帮助 |

- 未知指令回复「未知指令 + 帮助」;取不到 QQ 号回复"无法识别你的 QQ 号"
- 指令异常统一兜底回复,不崩插件;后端不可达统一回复"后端不可达,请稍后再试"

## 绑定流程(完整链路)

```
玩家 QQ 群发 /dp 绑定
  → 插件 POST /api/astrbot/bind/request {qq}
  → 后端生成验证码(内存,5 分钟,单次)
  → 插件私聊发送验证码
  → 玩家二选一确认:
     a) 网页「个人中心 → QQ 绑定」输码
     b) 游戏内 /xmw qq bind <码>
  → 绑定落库(dp_user.qq_number),/dp 查询 验证
```

- 群聊投递私聊失败时,提示玩家主动私聊机器人重发(常见于隐私设置)
- 验证码确认通道与限频(1/分、5/天)在后端实现

## 群服消息桥规则

### 上行(群 → 服)

转发条件全部满足才发:群在 `forward_groups` 内 + 文本非空 + 非 `/` 指令 + 非机器人自身消息 + 首词不是 `dp/dreamport`(指令不进服)。

`mode` 行为由**后端群绑定配置**决定(all/prefix),插件只负责投递——所以改 all/prefix 在管理后台改,不用动插件。

### 下行(服 → 群)

SSE 事件按 `group` 字段路由发群;内容(聊天/进退服/网页消息)由后端模板渲染;单群 `forward_join_quit=false` 时后端不下发该群的进退服事件。

### 防回环

机器人回复、自身消息一律过滤,不会再次上行进服形成死循环。

## 排障速查

| 现象 | 检查 |
|---|---|
| 所有请求"后端不可达" | `backend_url`;后端进程;`astrbot.enabled` 是否开启(关闭=403) |
| 自检日志 api_token 显示 `!!` | 没配令牌或没复制完整 |
| 指令正常但群消息不转发 | 群号是否在 `forward_groups`;后端群绑定 JSON 群号是否一致 |
| 私聊验证码发不出 | `platform_id` 与适配器 ID 不一致;玩家隐私设置 |
| 服→群没消息 | SSE 是否连接(日志);令牌;群号;后端模板 |
| 重启后 SSE 没重连 | SSE 惰性启动——群里随便发一条消息触发 |
