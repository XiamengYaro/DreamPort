# 社区功能 · 论坛 / 投票 / 反馈工单 / Webhook

一级导航「社区」页(`/community`)的三个 tab 与后台对应管理页的使用说明。

## 论坛(进阶版)

- **游客可读**:未登录可浏览帖子与回复;发帖/回帖/点赞需登录
- 板块由后台「论坛管理」创建(名称/描述/排序/只读开关);板块锁定时仅管理员可发帖
- 帖子支持:**置顶、精华、锁定**、@提及(解析正文 `@用户名`,通知对方)、10 分钟内可编辑自己帖子(留「已编辑」痕)、帖子与回复点赞
- 防刷:发帖 3 条/天、回帖 10 条/天、30 秒限频;敏感词过滤与聊天同口径(`sensitive.words`)
- **审核模式**(后台「论坛管理 → 论坛设置」可切换):
  - 默认**先发后审**:发布即公开,敏感词替换 + 管理员事后删除兜底
  - **先审后发**:帖子/回复进入待审队列,仅作者与管理员可见,审核通过后公开展示;通过/拒绝都会通知作者
- Web 端 Markdown 渲染与服务端净化(DOMPurify 白名单)

## 投票

- 后台「投票管理」创建(标题/说明/**单选或多选**/选项),创建后为草稿,「开启」后玩家可见并**给全站玩家发铃铛通知**;可关闭、删除、改选项(改选项清空选票)
- **结果可见性逐场可配**:
  - `实时公开`(默认):任何人都能看到票数与百分比
  - `结束后公开`:投票结束(手动关闭或到截止时间)或自己投完票后才可见
- 管理员始终可见完整结果

## 反馈工单(多轮对话式)

- 玩家提交建议/问题(分类:功能建议/问题反馈/其他),**每天最多 3 条**;可在工单里持续追问,管理员回复时状态变「已回复」
- 管理员回复会同时给玩家**站内铃铛 + 邮件**(模板 `feedback_reply_*`,外置覆盖规则同其他邮件);玩家确认解决或管理员均可关闭
- 后台「反馈工单」Tab:按状态筛选 + 对话式回复界面

## Webhook 事件推送

后台「系统设置 → Webhook 事件推送」:

- 配置多个目标 URL(各带独立可选 secret),事件发生时异步 `POST` JSON:`{event, time, ...数据}`
- 签名:头 `X-DP-Signature: sha256=<HMAC-SHA256(secret, timestamp + "." + body)>`、`X-DP-Timestamp`(毫秒),供接收端防伪造
- 事件过滤留空 = 推送全部;支持「发送测试事件」按钮
- 事件源为审计日志骨架,主要事件类型:

| 事件 | 触发 |
|---|---|
| review.approved / rejected / banned / unbanned | 白名单审核与封禁 |
| appeal.approved / rejected | 申诉处理 |
| questionnaire.submitted | 问卷提交 |
| reward.sent | 奖励礼包发放 |
| feedback.created / replied / closed | 反馈工单 |
| forum.* (thread_submit / reply_submit / thread_approve / thread_pin …) | 论坛全部审核与内容动作 |
| poll.created / opened / closed | 投票生命周期 |
| community.village_approve / machine_approve … | 村谱/机器审核(本次已补审计) |
| server.token_issue / server.disable … | 服务器管理动作 |

- 失败重试 2 次(1s/3s 退避),最终失败记录后端日志;不落表

## 审计与日志

社区全部管理动作(审核/板块/投票/工单/Webhook 设置)均写审计日志(后台「审计日志」Tab 可查);村谱/机器审核此前的审计缺口已一并补上。
