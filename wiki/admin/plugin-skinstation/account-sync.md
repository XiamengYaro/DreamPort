# 皮肤站插件 · 账号同步规则

DreamPort 是账号权威,皮肤站跟随。所有同步由 DreamPort 后端在用户操作后发起,以 **email 定位**皮肤站账号、`X-Dreamport-Secret` 鉴权。

## 注册三类型与皮肤站的关系

| DreamPort 注册类型 | 皮肤站动作 |
|---|---|
| 正版 Java | 不开通(与皮肤站无关) |
| **非正版 Java** | 注册成功即 `provision`:账号(email/昵称/密码)+ 初始积分(`user_initial_score`,默认 1000)+ 同名角色 |
| 纯基岩版 | 不开通 |

同步细节(注册场景):

- **密码**:直接采用玩家在 DreamPort 填写的注册密码(服务端信道传输,插件侧立即 `changePassword` 哈希落库),玩家注册完即可用同款账密配启动器
- **角色名**:玩家填的游戏 ID(= DreamPort 用户名);按 BS 官方规则校验(`PlayerName` + 长度 + 重名),校验不过/重名则**不建角色**并在响应带原因(注册不受影响)
- **幂等**:同 email 已有账号则不重建,但会补同名角色(修复此前开通失败的账号)
- 建角色**不扣** `score_per_player`(角色是注册赠送的;玩家在皮肤站手动加角色才扣)

## 用户操作触发的同步

| DreamPort 操作 | 皮肤站动作 | 失败影响 |
|---|---|---|
| 修改密码 | `update-password`:按 email 改密 | 不阻断本站改密;响应提示"皮肤站同步失败,可稍后重试" |
| 修改 Minecraft ID | `update-player-name`:旧角色改名;用户无角色则按新名新建;新名被占返回原因 | 不阻断本站;提示同步结果 |
| 修改邮箱 | `update-email`:**先改皮肤站,成功才改本站**(email 是关联键,顺序错会导致下次 SSO 重建第二个账号) | 皮肤站失败 → **本站邮箱不修改**,报错带原因 |

## 语义约定(所有同步接口)

| 场景 | 结果 |
|---|---|
| DreamPort 互通未启用/配置不全 | 无操作成功(不阻断玩家任何正常操作) |
| 皮肤站无此 email 账号(404) | 无操作成功(未关联的账号改密/改邮箱不需要同步) |
| 皮肤站传输失败 | `ok=false`;改密/改 ID 静默提示,改邮箱阻断 |
| 新角色名被占用 | 返回 "player name already taken",前端展示 |

## 存量账号开通路径

互通上线前的 DreamPort 用户在皮肤站没有账号:

1. **控制台一键开通**(推荐):输入当前 DreamPort 密码 → 后端校验密码后调 provision → 账号+角色+积分一步到位,密码与 DP 同款
2. **SSO 首登兜底**:去皮肤站点「使用 DreamPort 账号登录」→ 自动注册(**初始积分 + 随机密码**);引导玩家改一次 DreamPort 密码即自动同步

## 玩家在皮肤站的手动操作

- 手动添加额外角色:走 BS 官方流程(扣 `score_per_player`)
- 手动改角色名:插件同步只认「DreamPort 游戏名」对应的角色;玩家自行改过角色名后,再改 DreamPort 游戏名会提示"player not found"且**不会误改**玩家自建的角色(仅在用户没有任何角色时才自动新建)
